# simchart-web — 닮은꼴 차트(웹판) 배포물

이 저장소는 웹 앱 **닮은꼴 차트**의 빌드 결과(정적 파일)만 담은 **앱 배포물**이다. 소스 코드 저장소가 아니며, 데이터 API·데이터 피드가 아니다.
화면: https://heoseongilml.github.io/simchart-web/

- 과거 차트 학습용이며 투자 판단의 근거가 아닙니다.
- 데이터: Binance Vision (CC BY-NC-SA 4.0) — https://github.com/binance/binance-public-data 의 BTCUSDT 1시간 봉 klines 공개 파일(data.binance.vision)로 만든 앱 내부 자산(`data/btcusdt-1h.bin`, `data/btcusdt-1h.json`).
- 라이선스: 위 데이터와 그 파생물(`data/`)은 원 데이터와 같은 **CC BY-NC-SA 4.0**(https://creativecommons.org/licenses/by-nc-sa/4.0/)으로, **비상업 용도로만** 배포한다. Binance Vision 이용 약관을 따른다.
- 광고·분석 SDK·유료 기능 없음. 앱 갱신은 하루 1회.
